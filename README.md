# Sample family tree

Adapted from genealogical research. Names, places, dates and record details were changed, and no
one who may still be living is included.

## What is here

| File | Contents |
|---|---|
| `sample.ged` | the tree in GEDCOM 5.5.1 |
| `sample.gramps` | the same tree as Gramps XML |
| `media/` | 87 portraits at 240×300, used by both |

Keep `media/` beside the two files so the portraits attach. In Gramps, import `sample.gramps` into
a new, empty family tree, then set Edit → Preferences → Family Tree → Base media path to this
folder.
